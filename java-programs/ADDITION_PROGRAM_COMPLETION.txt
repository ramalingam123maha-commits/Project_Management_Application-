                              METHODS
════════════════════════════════════════════════════════════════════════════

Core Addition Methods:
  1. add(int, int) → int
     - Adds two integers
     - Example: add(5, 3) = 8

  2. add(double, double) → double
     - Adds two floating-point numbers
     - Example: add(5.5, 3.2) = 8.7

  3. addMultiple(int...) → int
     - Adds any number of integers using varargs
     - Example: addMultiple(1, 2, 3, 4, 5) = 15

  4. addMultiple(double...) → double
     - Adds any number of floating-point numbers
     - Example: addMultiple(1.5, 2.5, 3.0) = 7.0

  5. addArray(int[]) → int
     - Sums all elements in an integer array
     - Throws: IllegalArgumentException if empty or null
     - Example: addArray([10, 20, 30]) = 60

  6. addArray(double[]) → double
     - Sums all elements in a double array
     - Throws: IllegalArgumentException if empty or null
     - Example: addArray([2.5, 3.5, 4.0]) = 10.0

  7. average(int...) → double
     - Calculates average of multiple integers
     - Throws: IllegalArgumentException if no numbers
     - Example: average(10, 20, 30, 40) = 25.0

  8. average(double...) → double
     - Calculates average of multiple floating-point numbers
     - Throws: IllegalArgumentException if no numbers
     - Example: average(5.0, 10.0, 15.0, 20.0) = 12.5

Supporting Methods:
  - interactiveMode() - User interactive addition
  - demonstrationMode() - Predefined examples
  - showMenu() - Main menu display
  - quickAdd(Scanner) - Quick two-number addition
  - main(String[]) - Program entry point
